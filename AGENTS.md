# Agent instructions

## Attribution

AI-assisted work is welcome here, but keep it low-key:

- Do not add AI attribution trailers (e.g. `Co-Authored-By` lines for an AI tool, session IDs or links) to commit messages.
- Do not include "Generated with" footers, session links, or similar attribution in pull request descriptions, PR/issue comments, or code comments.
- Write commit messages and PR descriptions as a normal contributor would.
