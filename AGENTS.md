# Agent instructions

## Attribution

Agents are collaborators on this project, and we'd like that stated
honestly rather than hidden or hyped.

- Our collaboration with agents is acknowledged at the project level
  (see the README), in our own words, rather than stamped on every
  commit or comment.
- Don't add redundant tool boilerplate: no "Generated with" footers, session IDs,
  or session links in commits, PRs, or code comments. These describe a
  tool, not a contribution.
- Do describe your work accurately. Commit messages and PR descriptions
  should say what changed and why, and flag any judgment calls a
  reviewer should look at.
- If someone asks how something was made, answer plainly and honestly.
