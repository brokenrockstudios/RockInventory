# Claude Code instructions

## Attribution

AI-assisted work is welcome here, but keep it low-key:

- Do not add `Co-Authored-By`, `Claude-Session`, or other AI attribution trailers to commit messages.
- Do not include session links, "Generated with Claude Code" footers, or similar attribution in pull request descriptions, PR/issue comments, or code comments.
- Write commit messages and PR descriptions as a normal contributor would.
